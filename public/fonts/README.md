# Fuentes del portfolio

La combinación se identificó en https://yikesdude.com/ y se obtuvo desde Google
Fonts, no desde los archivos del sitio de referencia. Los WOFF2 se sirven
localmente y contienen el subconjunto Latin, incluidos los caracteres del español.

| Fuente | Uso | Pesos variables |
|---|---|---|
| Fraunces | Títulos | 400–700 |
| Geist | Texto e interfaz | 400–700 |
| JetBrains Mono | Navegación, etiquetas y números | 400–600 |

Se incluyen las licencias SIL Open Font License de cada familia. Fuentes oficiales:

- https://github.com/google/fonts/tree/main/ofl/fraunces
- https://github.com/google/fonts/tree/main/ofl/geist
- https://github.com/google/fonts/tree/main/ofl/jetbrainsmono

Descarga: 28 de octubre de 2026. Tres archivos WOFF2, 97.452 bytes en total.
`font-display: swap` permite mostrar el texto mientras se cargan; Geist y
Fraunces se precargan desde el HTML. No requiere conexiones a Google al visitar el sitio.
