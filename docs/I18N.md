# Selector ES/EN

El encabezado incluye un botón ES/EN accesible por teclado. El español es el
idioma inicial; la elección se conserva en `localStorage['portfolio-language']`.
El idioma elegido traduce la interfaz y el carrusel con Transloco 8.4.0,
actualiza `html[lang]` y la descripción de la página y usa meses en español o
inglés. No cambia la selección del tema ni las secciones de navegación.

Las traducciones de la interfaz están en `src/app/shared/data/translations.ts`:
cada clave contiene `[español, inglés]`. `LanguageService` registra los dos
catálogos en Transloco al iniciar; no hay solicitudes adicionales para cargar
archivos de idioma ni dependencias de servicios externos de traducción.

El contenido profesional procede de Django. Al seleccionar inglés,
`PortfolioApiService` agrega `?lang=en` a los endpoints y cancela solicitudes
anteriores. La API conserva el parámetro en las siguientes páginas. En español
se usan las rutas originales. Las URLs de imágenes y certificados no cambian:
`/assets/...` resuelve desde este frontend y el certificado sigue abriendo su
enlace en una pestaña nueva. Los documentos externos mantienen su idioma original.

El backend traduce los textos publicados mediante su catálogo versionado
`portfolio/localization.py`. Al editar contenido en Admin, actualizar también
ese catálogo; una traducción faltante muestra el texto original. La biblioteca
no genera traducciones por sí sola.

## Publicar

Desplegar primero el cambio del backend en Render y verificar que
`https://portfolio-backend-6ecn.onrender.com/api/v1/perfil/?lang=en` devuelve
la biografía en inglés. Luego subir este frontend para que Vercel lo despliegue.
No se necesitan variables nuevas y se conservan ambos archivos de entorno.

## Verificar

```powershell
npm ci
npm test -- --watch=false
npm run build -- --configuration production
```

Las pruebas unitarias verifican persistencia, almacenamiento bloqueado,
interfaz, contenido de API, fechas y cancelación de respuestas anteriores.
Para la regresión conectada con Django real, ejecutar
`scripts/run_regression.py` desde el backend: crea PostgreSQL de prueba aislado
y ejecuta `e2e/real-api.spec.ts`, incluidos los recorridos ES/EN, en tres motores
de navegador y tres tamaños. No utiliza ni modifica producción.
